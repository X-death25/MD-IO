# 6-Button Controller Adapter (RP2040)

> Use a standard USB gamepad as a Sega 6-button controller (Mode/X/Y/Z support) on your Mega Drive.

## 🧠 Overview

USB-to-DB9 passthrough for the extended 6-button Sega pad protocol — handles the standard 3-read TH cycle needed to unlock the extra buttons on games that support them.

## 🛠️ Firmware

Pick the `.uf2` matching your USB gamepad from [`/firmware`](./firmware):
